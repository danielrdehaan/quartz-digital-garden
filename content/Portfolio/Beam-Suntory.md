# Beam Suntory

**Role**: Sound/Music Designer

## Project Overview

Created music and sound effects for an interactive installation at Beam Suntory's US headquarters via Waveplant.

The installation provides an immersive brand experience, showcasing Beam Suntory's portfolio of spirits through interactive audio-visual elements.

## Responsibilities

- Music composition for the installation
- Sound effects design
- Interactive audio programming
