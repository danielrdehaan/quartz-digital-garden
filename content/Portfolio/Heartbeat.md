# Heartbeat

**Role**: Audio/Music Programmer & Designer

## Project Overview

Designed and programmed custom audio software and composed music for an interactive installation produced by Humancraft. Exhibited in San Francisco and New York (2023).

Heartbeat is an interactive installation that responds to participants' presence and movement, creating a dynamic audio-visual experience that evolves in real-time.

## Responsibilities

- Custom audio software development
- Music composition
- Interactive audio system design
- Real-time audio programming
